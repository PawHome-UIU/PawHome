4.  SITE CHROME   --  what makes all three areas look like one product
################################################################################

  PublicLayout    components/layout/PublicLayout.jsx
      Wraps every public page. It is just PublicNav + the page + PublicFooter.

  PublicNav       components/layout/PublicNav.jsx
      The top menu bar. Buttons: "Log in", "Sign up". Mobile menu uses useState.
      >>> I OWN NAVIGATION. When the other two add a page that needs a menu
          link, they ask me. One person owning the menu is why the site
          structure stays consistent.

  PublicFooter    components/layout/PublicFooter.jsx
      Footer links and the logo.

  AuthLayout      components/layout/AuthLayout.jsx
      The centred frame around login and register.
      >>> TEAMMATE 1'S FOUR AUTH PAGES ALL IMPORT THIS FROM MY FOLDER.

  ScrollToTop     components/layout/ScrollToTop.jsx
      Jumps to the top of the page whenever the address changes.
      Uses useEffect + useLocation. It sits in App.jsx, inside the Router but
      outside Routes, so it sees every navigation.
      >>> WHY IT EXISTS: in a single page app the browser never reloads, so
          your scroll position stays where it was. Clicking a footer link
          would drop you halfway down the next page.

  Logo / PawIcon  components/brand/Logo.jsx, PawIcon.jsx
      The logo and the paw mark, in one place. Logo is built from PawIcon.
      Used by PublicNav, PublicFooter, AuthLayout, PortalShell and
      Teammate 1's auth pages.

  SECTIONS        components/sections/
      SectionHeading.jsx   a titled section header
      FeatureRow.jsx       an icon + text + image row
      CtaBand.jsx          the coloured "get started" strip (uses Button)
      >>> These are why Landing, About, Features and Services share the same
          rhythm instead of each inventing its own spacing.

################################################################################
6.  THINGS TO KNOW BEFORE THE DEMO
################################################################################

* I DO NOT own components/ui/ -- that is Teammate 2. I import Button, Card,
  Modal, Input, Tabs, Dropdown, Accordion and SuccessModal from them.
* I DO NOT own PetCard -- that is Teammate 1's. My landing page uses it for
  the featured pets strip.
* I DO own DataTable and StatTile, and Teammate 2 reuses them on three of
  their pages. Cross-team reuse in both directions.
* My pages read from src/data/admin.js, not the backend yet.
* Connecting the shelter table is one line:
        useEffect(() => { api.get("/shelters").then(r => setRows(r.data)); }, []);
  and "Add Shelter" becomes api.post("/shelters", form).
* No route is guarded yet. Typing /admin works for anyone. The real protection
  is @PreAuthorize("hasRole('ADMIN')") on the backend endpoints -- even with
  the page open, every request it makes would be refused with 403.
